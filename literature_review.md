# Literature Review

## Symbolic–KAN: Kolmogorov-Arnold Networks with Discrete Symbolic Structure for Interpretable Learning (https://arxiv.org/pdf/2603.23854)
 
### Problem Statement: KANs have improved function approximation and training dynamics. But when the estimated simple primitives for a functional form becomes more opaque(complex) than standard MLP models, which limits its usefullness in interpretability. (Yet to complete).

### Methodology : Symbolic-KAN first learns a scalar projection of the input features through trainable linear combinations, enabling the discovery of meaningful feature interactions. A symbolic univariate function is then applied to each learned projection, replacing the large matrix of edge-wise functions in standard KAN with a compact and interpretable symbolic representation.
